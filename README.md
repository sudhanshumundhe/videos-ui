
# 🎬 Vidos-UI (Video Streaming Web App)

A modern YouTube-style video streaming UI built using **React JS**, featuring a clean design, dark/light mode, search functionality, and fullscreen video player.

---

## 🚀 Live Features

- 🎥 Fetch videos from API (YouTube public API)
- 🔍 Real-time search filter
- 🌙 Dark / Light mode toggle
- 📺 Fullscreen video player (YouTube embed)
- 📂 Multiple pages (Home / All Videos)
- 🖼️ Responsive video grid layout
- ⚡ Fast and simple UI design

---

## ▶️ How to Run Project

### 1. Clone repo
```bash
git clone https://github.com/your-username/videos-ui.git
````

### 2. Install dependencies

```bash
npm install
```

### 3. Run project

```bash
npm run dev
```

## 🌐 Features in Detail

### 🎥 Video Grid

Displays all videos in a responsive grid layout.

### 🔍 Search

Instant filtering of videos by title.

### 🌙 Theme Switch

Switch between dark and light mode.

### 📺 Player

Click any video → opens fullscreen YouTube player.
